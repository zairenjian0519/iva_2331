## 环境部署

1. 安装 `node 12.22.9` 及 `yarn` ，参见 [ftp://lm@10.10.10.10/node](ftp://lm@10.10.10.10/node)（文件管理器打开）

``` cmd
nvm install 12.22.9
nvm use 12.22.9
```


2. 安装依赖
``` cmd
yarn auto-install
```


<br>


## 运行代码

1. 修改服务端IP配置： [.env.development](.env.development)


2. 构建代码
``` cmd
yarn dev
```

3. 打开网页 [http://localhost:3100/](http://localhost:3100/)
